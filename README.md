# HC Emoji CLI

CLI for interacting with Hack Club slack emojis! Made for Hack Club Giftbox

## Installation

### Install from NPM:

```bash
npm i -g hcemoji
```

### Install from source:

```bash
git clone https://github.com/Charmunks/hcemoji
cd hcemoji
npm i
npm link
```

## Commands

- ``hcemoji view <emojiname>``: View an emoji in your terminal as ascii art
- ``hcemoji download <emojiname> <filename>``: Download an emoji to a file
